| Version | Supported          |

## Reporting a Vulnerability

Security and candidate privacy are foundational principles of this platform. If you discover a security vulnerability or privacy leak, please do **NOT** open a public issue.

Instead, please report the vulnerability privately by reaching out directly:
- **Developer & Maintainer**: Atique Ullah
- **LinkedIn**: [https://www.linkedin.com/in/atiqueullahlimon](https://www.linkedin.com/in/atiqueullahlimon)

Please include:
1. Description of the vulnerability and potential impact.
2. Step-by-step instructions or proof-of-concept to reproduce the issue.
3. Affected components, endpoints, or dependencies.

You will receive an acknowledgment within 48 hours, and a resolution will be coordinated promptly.
